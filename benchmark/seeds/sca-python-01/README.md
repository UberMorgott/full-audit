# Seed: sca-python-01 (controlled SCA benchmark)

This is a **controlled benchmark seed for the full-audit SCA path**, pinned-vulnerable-by-design: `requirements.txt` deliberately pins six popular PyPI packages (Jinja2, PyYAML, requests, urllib3, Flask, cryptography) at old versions each carrying one or more published CVEs. It is not a real application — it exists only to exercise the dependency-scanning pipeline and produce objective recall/precision numbers. The ground truth (`ground-truth.yaml`) is sourced independently from the [osv.dev](https://osv.dev) API (a `/v1/query` per pinned `package@version`), deduplicated to the distinct set of CVE ids, with severity/CVSS taken from each osv record per the frozen CVSS↔band crosswalk in `benchmark/ground-truth.schema.md`. GT + the matching rule were committed and git-tagged (`bench-prereg-sca-python-01`) **before** any scanner run, so the rule cannot have been tuned to the results.
